# Program/outputs

В этой папке появляются результаты работы программы. Большинство файлов здесь
создается автоматически и может быть пересоздано полным запуском pipeline.

## Что здесь находится

| Файл/папка | Зачем нужен |
|---|---|
| `datasets/` | Синтетические датасеты: список запусков, кадры и траектории агентов. |
| `features/` | Таблицы признаков, рассчитанных по траекториям. |
| `forecast/` | Результаты прогнозирования динамики толпы. |
| `anomaly/` | Предсказания и метрики поиска аномалий без учителя. |
| `eda/` | EDA-отчет, таблицы и графики для анализа данных. |
| `models/` | Контрольные модели с учителем и их метрики. |
| `final_report/` | Полный итоговый отчет по всем шагам pipeline. |
| `.gitkeep` | Служебный файл, чтобы пустая папка была видна в Git. |

## Как это связано с проектом

`outputs` является конечной точкой pipeline. Сначала программа создает
синтетические данные, потом признаки, потом прогнозы, аномалии, графики,
метрики и итоговый отчет. Эти файлы удобно смотреть после запуска, чтобы понять
результат проекта.

## Что смотреть в первую очередь

1. `final_report/demo/project_report.md` - полный отчет по результатам pipeline.
2. `eda/demo/eda_report.md` - разведывательный анализ данных, траекторий, признаков и временных диагностических пиков.
3. `anomaly/demo/unsupervised_metrics.json` - качество поиска аномалий.
4. `forecast/demo/forecast_metrics_by_split.csv` - качество прогноза.
5. `datasets/demo/runs.csv` - какие запуски были созданы.

В папке `eda/demo/tables` отдельно создаётся `feature_dictionary.csv`. Это
короткий словарь признаков: техническое имя, русское название и простое
объяснение. Он нужен, чтобы графики и таблицы были понятны без чтения кода.

## Какие файлы создаются автоматически

Почти все содержимое подпапок `datasets`, `features`, `forecast`, `anomaly`,
`eda`, `models` и `final_report` создается автоматически. Если
удалить эти результаты, их можно восстановить командой:

```bash
python scripts/run_all.py
```

Запускать команду нужно из папки `Program`.
