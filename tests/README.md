# Program/tests

В этой папке лежат автоматические проверки проекта. Они помогают убедиться, что
основные части программы запускаются и создают ожидаемые файлы.

## Что здесь находится

| Файл/папка | Зачем нужен |
|---|---|
| `test_project_structure.py` | Проверяет, что важные папки и файлы проекта на месте. |
| `test_social_force.py` | Проверяет базовую логику модели Хелбинга и симуляции. |
| `test_dataset.py` | Проверяет создание синтетического датасета. |
| `test_features.py` | Проверяет расчет признаков, их описания и защиту от утечки. |
| `test_forecasting.py` | Проверяет блок прогнозирования. |
| `test_unsupervised_anomaly.py` | Проверяет поиск аномалий без учителя. |
| `test_baselines.py` | Проверяет контрольные модели с учителем. |
| `test_eda.py` | Проверяет создание EDA-таблиц, словаря признаков и графиков. |
| `test_reporting.py` | Проверяет создание итогового отчета по pipeline. |
| `test_ui.py` | Проверяет, что UI-модуль можно импортировать. |

## Как это связано с проектом

Тесты не являются частью научного результата, но они показывают, что программа
собирается и работает воспроизводимо. Это особенно полезно перед коммитом или
перед демонстрацией проекта.

## Что смотреть в первую очередь

1. `test_project_structure.py` - общая структура.
2. `test_dataset.py` и `test_features.py` - данные и признаки.
3. `test_unsupervised_anomaly.py` - главный блок аномалий.

## Как запускать

Из папки `Program`:

```bash
python -m pytest
```

Для проверки стиля кода:

```bash
python -m ruff check .
```
