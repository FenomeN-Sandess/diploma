# Program/src/crowd_anomaly/core

Эта папка отвечает за нижний уровень модели: геометрию, социальные силы,
симуляцию и сохранение траекторий. Это основа, на которой строятся все
последующие данные.

## Что здесь находится

| Файл/папка | Зачем нужен |
|---|---|
| `geometry.py` | Простые геометрические функции и ограничения области движения. |
| `social_force.py` | Расчет сил модели Хелбинга: движение к цели, отталкивание, стены и контактные члены. |
| `simulation.py` | Пошаговое обновление положения и скорости агентов. |
| `export.py` | Сохранение результатов симуляции в `trajectories.csv` и `run_metrics.json`. |
| `__init__.py` | Служебный файл Python-пакета. |

## Как это связано с проектом

Сначала сценарий превращается в набор агентов и целей. Затем симуляция на каждом
шаге считает силы, обновляет скорости и координаты. После этого `export.py`
записывает траектории, из которых позже считаются признаки и строятся модели.

## Что смотреть в первую очередь

1. `social_force.py` - какие силы действуют на агента.
2. `simulation.py` - как проходит один шаг симуляции.
3. `export.py` - какие поля попадают в траектории.

## Что создается автоматически

Эта папка сама не хранит результаты. Она создает данные в `Program/outputs`,
когда запускается датасет или полный pipeline.
