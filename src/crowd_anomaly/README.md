# Program/src/crowd_anomaly

Это основной Python-пакет программной части ВКР. Здесь собраны модули, которые
создают данные, считают признаки, обучают простые модели и формируют отчеты.

## Что здесь находится

| Файл/папка | Зачем нужен |
|---|---|
| `core/` | Базовая физика: геометрия, модель Хелбинга, симуляция и экспорт траекторий. |
| `scenarios.py` | Превращает YAML-описания сценариев в объекты для симуляции. |
| `dataset.py` | Строит синтетический датасет запусков. |
| `features.py` | Считает числовые признаки по траекториям и хранит их русские описания. |
| `forecasting.py` | Прогнозирует следующее агрегированное состояние толпы. |
| `anomaly.py` | Ищет аномальные запуски без учителя. |
| `baselines.py` | Обучает контрольные модели с учителем. |
| `eda.py` | Делает таблицы, графики и EDA-отчет. |
| `reporting.py` | Собирает итоговый отчет по всем результатам pipeline. |
| `plotting.py` | Общие функции для графиков. |
| `ui.py` | Простая Streamlit-страница для просмотра проекта. |

## Как это связано с проектом

Скрипты из `Program/scripts` в основном только читают аргументы командной
строки и вызывают функции из этой папки. Поэтому именно здесь находится главная
логика проекта.

## Где реализованы методы без учителя

Основной блок поиска аномалий находится в `anomaly.py`. Там сравниваются пять
вариантов расчёта: `pca_physics`, `pca_reconstruction`, `physics_only`,
`isolation_forest` и `hybrid_iforest_physics`.

В итоговом результате используется `pca_physics`. Он объединяет ошибку
восстановления PCA и физический показатель по силе, плотности и близким парам.
Такой вариант показал лучший F1 на тестовой части: `0.774`.

## Что смотреть в первую очередь

1. `core/social_force.py` - как считаются силы Хелбинга.
2. `dataset.py` - как создаются запуски и файлы датасета.
3. `features.py` - как траектории превращаются в признаки и где описан смысл признаков.
4. `anomaly.py` - как считается показатель аномальности.
5. `forecasting.py` - что именно прогнозирует модель.
6. `plotting.py` - как строятся графики EDA, траекторий, признаков и временных пиков.
7. `reporting.py` - как собирается полный отчет по результатам.
