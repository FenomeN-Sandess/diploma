# Program/src

В этой папке находится исходный код Python-пакета. Именно отсюда берутся модули,
которые используют скрипты из `Program/scripts`.

## Что здесь находится

| Файл/папка | Зачем нужен |
|---|---|
| `crowd_anomaly/` | Основной пакет проекта с симуляцией, признаками, моделями и EDA. |

## Как это связано с проектом

`src` подключается как Python-пакет при установке проекта командой
`python -m pip install -e ".[dev]"`. После этого скрипты могут импортировать
модули вида `crowd_anomaly.dataset`, `crowd_anomaly.features` и так далее.

## Что смотреть в первую очередь

1. `crowd_anomaly/README.md` - описание основного пакета.
2. `crowd_anomaly/core/README.md` - физическая модель и симуляция.
3. `crowd_anomaly/features.py` - расчет признаков и их короткие русские описания.
4. `crowd_anomaly/anomaly.py` - основной метод поиска аномалий.
5. `crowd_anomaly/reporting.py` - сбор итогового отчета по результатам.
